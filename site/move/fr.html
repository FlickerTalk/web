Transférer FlickerTalk vers un nouveau téléphone

Ce lien vient du code que FlickerTalk affiche sur un nouveau téléphone. Lu depuis votre ancien téléphone, il transfère votre identité, vos contacts et vos messages vers le nouveau.

Comment transférer

  1. Sur le nouveau téléphone, installez FlickerTalk. Ouvrez-le et touchez « J’ai FlickerTalk sur un autre téléphone » pour afficher le code. S’il affiche déjà le code, passez cette étape.
  2. Sur l’ancien téléphone, ouvrez FlickerTalk. Allez dans Paramètres → « Transférer vers un nouveau téléphone ».
  3. Lisez le code du nouveau téléphone. Touchez « Scannez le code du nouveau téléphone » et scannez-le. Ou copiez l’adresse de cette page depuis la barre d’adresse (c’est le lien complet), collez-la dans « Ou collez son lien » et touchez « Transférer et effacer ». Une fois tout transféré, l’ancien téléphone est effacé.

Votre navigateur n’envoie pas à notre serveur la partie du lien qui suit le #.
