FlickerTalk auf ein neues Telefon übertragen

Dieser Link stammt aus dem Code, den FlickerTalk auf einem neuen Telefon zeigt. Vom alten Telefon gelesen, überträgt er deine Identität, Kontakte und Nachrichten auf das neue.

So geht die Übertragung

  1. Hol dir FlickerTalk auf dem neuen Telefon. Öffne es und tippe auf „Ich habe FlickerTalk auf einem anderen Telefon“, damit der Code erscheint. Wenn der Code schon zu sehen ist, überspring diesen Schritt.
    Bald im App Store
  2. Öffne FlickerTalk auf dem alten Telefon. Geh zu Einstellungen → „Auf neues Telefon übertragen“.
  3. Lies den Code des neuen Telefons. Tippe auf „Scanne den Code des neuen Telefons“ und scanne ihn. Oder kopiere diesen Link, von dort, wo du ihn bekommen hast, oder aus der Adresse dieser Seite, füge ihn in das Feld „Oder füge seinen Link ein“ ein und tippe auf „Übertragen und löschen“. Sobald alles übertragen ist, wird das alte Telefon gelöscht.

Dein Browser sendet den Teil des Links nach dem # nicht an unseren Server.
